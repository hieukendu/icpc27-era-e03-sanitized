# ICPC 2027 ERA format check

The [official ERA call](https://conf.researchr.org/track/icpc-2027/icpc-2027-early-research-achievements--era-) was retrieved on 2026-11-11. It permits four pages of main content, including figures/tables/appendices, plus one optional references page. It specifies IEEEtran conference format at 10pt, without compsoc/compsocconf, and double-anonymous submission. It asks authors to identify the new idea, explain its novelty, and identify the single closest paper.

The revised manuscript retains the required class and font, answers those three questions in its introduction box, keeps author identities out, and separates the references using a page break after the main text. The complete data-availability disclosure must remain on page 4; checking only total page count is insufficient. The anonymous package URL is recorded in the manuscript's data-availability disclosure and points to the reviewer-facing mirror.
